# Prototype

Read [the host contract](../../../resources/host-contract.md) before acting.

1. Name the decision the prototype will settle. If there is no decision, route to feature.
2. Gather prior art when direction is open and identify candidate directions. Use the supplied direction when settled.
3. Build the smallest throwaway artifact in isolated scratch space with dependencies actually available. Prefer one labeled switcher for alternatives. Avoid production abstractions and speculative tests.
4. Observe the deciding behavior. Drive and capture each visual variant, or record actual output and timing for behavioral questions. If no driver exists, mark the decision unverified.
5. Present variants, observed evidence, tradeoffs, recommendation, and scratch location. State that the prototype is disposable. Route the chosen direction to feature or architect for production work.
