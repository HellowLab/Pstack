# Autopilot stack

Read [the host contract](../references/host-contract.md) before acting.

Full unattended owner coordination is unsupported without a tested host lifecycle and scheduler adapter. This package can describe or execute authorized in-session stack work, but must label that limitation.

Preserve the distinctive contract: build and verify a linear base-branch chain; the user owns landing. One coordinator changes topology, each implementation owner writes only its branch, and real independent verification gates each patch. Record exact heads and parents. Rebase bottom-up only when authorized; changed patches require new verification. Never merge, arm auto-merge, or close PRs through this playbook.

Deliver root and tip links, one actual verdict per link, pending gaps, and a durable handoff. Do not claim a persistent hourly audit or unseen worker progress.
