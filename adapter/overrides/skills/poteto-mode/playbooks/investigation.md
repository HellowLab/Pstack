# Investigation

Read [the host contract](../../../resources/host-contract.md) before acting.

1. Keep the task read-only. Route behavior questions to how and motivation questions to why.
2. Record throughput checkpoint: n/a, read-only investigation.
3. Return a cited explanation of overview, concepts, flow, ownership, and gotchas, or compare alternatives and give a recommendation.
4. Apply unslop. Give an honest judgment with reasons. Do not create a branch, edit product code, open a PR, or start monitoring from an investigation request. Route to feature or bug-fix only when the user authorizes that work.
