# Why

1. Anchor the question in real files, symbols, relevant commits, and linked review discussions. Follow history through renames where available.
2. Inventory seven evidence categories: source control, issues, long-form documents, team chat, infrastructure observability, error tracking, and product analytics. Discover only exposed authorized integrations. Even local git may be unavailable.
3. Query relevant available sources in scope. Record each category as searched, unavailable, or explicitly irrelevant, with the reason. Read-only research never authorizes posting to those systems.
4. Reconcile evidence chronologically. Distinguish documented facts, reasonable inferences, competing hypotheses, and unknowns. A missing search result does not prove a decision never existed.
5. Return the question, code anchor, findings, inference, hypotheses, unknowns, source coverage, and confidence. Preserve uncertainty when summarizing. For a planned change, add Preserve, Change, Avoid, and Risk constraints.
